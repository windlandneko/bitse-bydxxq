# 基于 Qt 的简易财务计算器实验报告

## 一、实验目的

使用 C++ 和 Qt 6 完成一个简易财务计算器，练习 Qt Designer、布局管理器、资源系统、QSS、信号与槽以及鼠标事件处理，并将界面显示与计算逻辑适度分离。

## 二、开发环境

- 操作系统：Ubuntu Linux
- 开发语言：C++17
- GUI 框架：Qt 6 Widgets
- 构建工具：CMake
- 开发工具：Qt Creator

## 三、系统设计

项目主要由以下模块组成：

- `MainWindow`：负责主界面、普通计算输入、结果显示和财务计算结果更新。
- `CalculatorModel`：负责四则表达式、单利和复利计算，避免将计算逻辑全部放入主窗口。
- `DraggableButton`：继承 `QPushButton`，实现数字和运算符的点击、拖拽输入。
- `FinancialDialog`：负责设置年利率、年限及单利/复利方式。
- `mainwindow.ui`、`financialdialog.ui`：使用 Qt Designer 描述界面和布局。
- `resources.qrc`、`calculator.qss`：管理图标和界面样式。

## 四、主要功能实现

### 1. 四则运算

`CalculatorModel::evaluate()` 使用数字栈和运算符栈解析表达式，保证乘除优先于加减，并支持小数和一元负号。程序会检测空表达式、无效字符、连续运算符、错误小数及除零等情况。计算失败时主窗口使用 `QMessageBox` 显示中文错误信息。

### 2. 财务计算

程序支持以下两种到期本息计算：

- 单利：`本金 × (1 + 年利率 × 年限)`
- 复利：`本金 × (1 + 年利率) ^ 年限`

本金在主窗口设置，年利率、年限和计算方式在财务参数对话框中设置。

### 3. 信号与槽及窗口通信

数字按钮的 `clicked` 信号连接到主窗口的输入追加逻辑；清除、退格、等号和参数设置按钮也通过信号与槽完成相应操作。

用户在参数对话框中单击“确定”后，对话框发出自定义信号：

```cpp
void parametersChanged(double rate, int years, bool compound);
```

主窗口接收该信号，保存参数并重新计算财务结果。采用信号与槽可以降低对话框与主窗口之间的耦合。

### 4. 鼠标拖拽输入

`DraggableButton` 重写了 `mousePressEvent()`、`mouseMoveEvent()` 和 `mouseReleaseEvent()`。按下鼠标时记录位置；移动距离超过系统拖拽阈值后，创建一个半透明按钮作为跟随阴影；释放鼠标时发出包含按钮值和全局坐标的 `dropped` 信号。主窗口将全局坐标转换到输入框坐标系，只有释放点位于输入框内部时才追加字符。

本项目选择虚函数重写，是因为拖拽行为属于按钮自身的鼠标交互。将事件处理封装在自定义按钮中比在主窗口安装多个事件过滤器更直接，便于所有数字和运算符按钮复用。

### 5. 界面与资源

主窗口和对话框均使用 `.ui` 文件设计，并使用垂直布局、网格布局和表单布局，窗口缩放时控件能自适应。QSS 设置了按钮圆角、悬停和按下效果、输入框焦点样式以及拖拽阴影。窗口 SVG 图标和 QSS 文件通过 `.qrc` 资源系统加载。

## 六、参考资料

开发过程中主要参考 Qt 6 帮助文档中的 `QMouseEvent`、`QPushButton`、`QDialog`、信号与槽、布局管理器及 Qt Resource System 相关内容。

## 七、实验总结

本实验完成了四则运算、单利/复利计算、错误提示、鼠标拖拽输入和跨窗口参数传递。通过将计算逻辑、自定义控件和界面代码分开，进一步理解了 Qt 的事件驱动机制、信号与槽以及资源管理方式。
