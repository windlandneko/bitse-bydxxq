# 界面设计规范

用户端使用森林绿、奶白和浅青柠色，大屏使用深蓝色。以下为项目采用的尺寸和组件规则。

## 参考及取舍

- [Material 3：间距与网格](https://m3.material.io/foundations/layout/grids-spacing/spacing)
  提供布局系统思路；本项目使用8为主、4为微调的间距节奏。
- [Android：默认无障碍行为](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)
  明确可交互元素至少48dp、图标操作有可读名称、装饰图不充当操作提示。
- [Now in Android 顶部栏](https://github.com/android/nowinandroid/blob/12f80da6518e161ed16a06a68e71fb8a873576d6/core/designsystem/src/main/kotlin/com/google/samples/apps/nowinandroid/core/designsystem/component/TopAppBar.kt)
  标题、导航和操作有独立区域，图标按钮提供语义名称。
- [Now in Android 内容卡片](https://github.com/android/nowinandroid/blob/12f80da6518e161ed16a06a68e71fb8a873576d6/core/ui/src/main/kotlin/com/google/samples/apps/nowinandroid/core/ui/NewsResourceCard.kt)
  采用16dp卡片内边距与圆角，图片区和内容区分开布局。
- [Jetsnack 首页](https://github.com/android/compose-samples/blob/018c5207fb63c4f78e5841bd8ddd4faabdf19d3a/Jetsnack/app/src/main/java/com/example/jetsnack/ui/home/Feed.kt)
  将位置、筛选和列表作为独立区域，底部导航稳定，列表自然滚动；找站页沿用这种任务结构。

文字对比检查参考[WCAG 2.2最小对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

Qt尺寸为逻辑像素，布局参考Android dp的空间关系。Lucide图标许可随源码保留。

## 用户端量化规则

| 项目 | 规则 | 检查方式 |
| --- | --- | --- |
| 页面边距 | 左右16；卡片内容再内缩16 | 页面标题、搜索、卡片外沿同线；卡片标题、分隔线、金额区同线 |
| 间距 | 8/16/24为主要层级；4用于图标与短标签；12用于紧凑组件 | 同类组件共用间距常量 |
| 顶部栏 | 64高；导航/右侧操作各独立48点击区 | 返回图标与标题垂直居中，窄屏标题不碰操作 |
| 底部导航 | 80高，三个等宽目的地 | 图标、选中标记及标签中心一致，点击区域互不重叠 |
| 图标 | 常规24；辅助20；操作区域至少48×48 | 返回、关闭、展开、导航、成功状态使用SVG图标 |
| 字体层级 | 页标题22，突出标题28，卡片标题16，正文14/16，辅助信息不低于12 | 同类标题字重统一，长地址可省略/换行但不压小字号 |
| 数值 | 金额、货币符号及单位沿同一基线 | 使用统一金额组件及baseline对齐 |
| 文字对比 | 常规正文及辅助文字目标至少4.5:1；灰字不能靠过低透明度形成层级 | 在奶白/白卡背景分别计算，禁用和装饰元素单独处理 |
| 圆角 | 普通卡片16，主视觉卡片24；圆形图标容器按用途 | 同类卡片使用相同圆角 |
| 表单 | 输入与主按钮共用内容宽度；标签与输入左沿同线 | 错误不挤坏按钮，昵称输入仍保留本地草稿 |
| 操作反馈 | 点击/按下、禁用、键盘焦点可辨认，图标有Accessible名称 | Tab可定位；正在请求不可重复提交；不吞掉网络或订单错误 |
| 信息密度 | 首屏优先展示找站和操作；装饰不占据主要阅读空间 | 360×800和430×860实际运行，重要按钮可见或自然滚动到达 |

整卡进入详情与卡内导航按钮保持独立命中区域。页面提示限于费用、自动停止、待结算、
冻结、断网等操作信息。技术说明放入文档，输入限制放在标签或占位文字中。

## 插图

登录页和首页使用同一套电动车与充电桩插图，保持视角、颜色与笔触一致。
由内建imagegen生成透明PNG，再转描为路径SVG；界面使用SVG，PNG保留为来源对照。

插图以奶白、鼠尾草绿、森林绿和少量青柠为主，在深绿卡片上留出可辨的亮面。
检查130px和220px显示宽度的轮廓与电缆连接，插图与正文各有自己的区域，不能侵入文字。
生成提示词、工具和转描参数与素材一同记录在 `apps/user-app/assets/illustrations/README.md`。

## 大屏量化规则

| 项目 | 规则 |
| --- | --- |
| 画布 | 延续1920×1080，等比适配1366×768，并检查两种尺寸 |
| 栅格 | 区块间距16，图表内容16/24内边距，标题起始线一致 |
| 顶部指标 | 四张KPI压缩到88高，32号主要数值；去除字符装饰图标，数字使用等宽数值 |
| 新增可视化 | 同行加入各站即时可服务能力：空闲/总桩数与状态分段，使用当前API真实数据 |
| 分段口径 | 空闲=idle；在用含预约=在线减空闲；暂不可用=总量减在线 |
| 文案 | 删除课程标签、模型长说明与“可点击”提示；保留连接异常、数据/预测过期及必要时间 |
| 交互 | 选中、hover、键盘focus明确，新增站点组件可选择并与地图同步；状态不能仅靠颜色说明 |
| 图表 | 轴、图例、工具栏不重叠，数值/单位统一，空数据/大数值/多站点有稳定显示 |

信息来源和模型评估见接口及设计文档。

## 验收方法

自动检查包含手机业务流程、11页QML加载和大屏浏览器验收。布局检查覆盖：
关键触控区域、金额基线、页面横向边界、顶部指标密度、新组件数据与交互。
同时人工检查各页截图的比例、对齐和文案。

截图见[界面精修验收](界面精修验收.md)，功能与工程验收见[验收报告](验收报告.md)。
