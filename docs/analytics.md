# 大屏与预测实现说明

需求依据：老师《东软电动汽车充电桩应用管理平台项目要求书》1.4(4)、1.4(5)。

## 大屏

Vue 3 + ECharts，C++ 业务服务同时提供静态页面与聚合 API。所有图表的业务值来自当前
SQLite 聚合，5 秒刷新；充值/结算、设备操作、站点新增与客户端操作共用同一数据库。
提供累计次数/营收/在线桩/注册用户、各站可用桩、站点排行、快慢充占比、时段热力、营收及订单、
未来 24h 负荷、经纬度站点选择和最近事件。

设计画布为 1920×1080，等比缩放到浏览器可用空间。原生 ResizeObserver 处理图表和
边框尺寸；动画尊重减少动态效果设置。连接断开保留最近快照，服务快照超过 30 秒及
预测超过 1 小时均有对应提示。

实际复用了 IofTV-Screen-Vue3 的 BorderBox13 SVG 路径并去除额外运行依赖。来源、提交
和完整 MIT 许可证在 `web/third-party/`；发布目录也带上 `public/third-party/` 中许可。
空间图根据当前站点经纬度绘制，以坐标轴和散点展示站点分布，不引用外网瓦片。
顶部各站可用桩与地图双向选择联动；空闲、在用/预约、暂不可用按当前桩状态计数。
课程来源和模型说明保留在接口、管理端和文档，页面只保留更新时间、高峰及异常提示。

## 预测

C++ 用 QProcess 异步启动 `uv run --project ml python -m ml.service`，只通过 JSON 文件交换
数据。Python 不打开数据库，结果由业务服务验证和保存。模型直接输出每桩未来 24 个
整点小时负荷，站级严格求和；提供 1/6/24 时距、空闲桩估计和相对高峰预警。

历史会话按实际重叠秒数分摊到小时，保证电量守恒。模型使用原点及以前的负荷滞后/
滚动均值、时段/星期/年度周期、法定日历与可选的已完成自然日天气；没有目标值滚动
泄漏。至少 14 天历史和 48 个非零小时才训练随机森林，其他桩明确使用基线。故障、
离线和重启的桩预测负荷为零，功率及空闲数都有物理上界。

相对高峰阈值为完整历史小时（包含零值）负荷的 85 分位数。无历史时使用容量的 70%。
标记用于需求高峰值守，不能被解释为设备过载。实时预测保留课程演示来源；天气数据
没有接入时显式标记缺失。法定日历依赖当前覆盖 2004–2026，未来年份明确标记未知。

## 真实数据验证与限制

嘉兴公开充电数据包含 441077 笔交易、13 个站点。本次按明确有效性规则保留 441072 笔，
分摊前后总电量均为 7249794.57 kWh。固定前 80% 时间训练、后 20% 测试，每 6 小时滚动
一个预测原点，共 7566 个样本/时距。训练样本的全部 24 个标签都早于训练截止时间。
天气只使用前一已经结束的自然日，标准化只使用训练数据，未根据测试指标选参数。

完整结果见 `ml/reports/jiaxing/report.json` 与 `report.md`。加入天气与日历后，固定随机
森林的 1/6/24h MAE 为 27.2004 / 27.6398 / 27.9880 kW，周周期基线为
22.9100 / 24.0883 / 24.1407 kW；当前模型没有超过该强基线，报告如实呈现。
历史会话内负荷是均匀分摊重建值，没有桩级秒级遥测；无交易小时视作零负荷，无法证明
采集系统从未漏报。这些是评估的适用范围，不能把公开回测的精度外推给当前课程站点。

## 验收

- `uv run --project ml pytest ml/tests -q`：8 项通过，覆盖部分小时守恒、非法会话、
  时间分割边界、目标及天气泄漏、日历范围、冷启动和实际训练分支、24h及功率/求和边界。
- `pnpm --dir web build`、`lint`、`format:check`，以及真实 `/api/dashboard` DTO 验证。
- `uv run --with playwright python web/tests/dashboard_smoke.py --url http://127.0.0.1:8080`：
  Chromium 两尺寸无滚动、七图表、88px指标、站点双向切换与键盘操作，另检查多站点分页、
  大数值、空数据和断连保留快照，捕获 JavaScript 异常。
- 实际后端联动：新用户充值100元、预约、充电、停止、结算276分后，次数加1、营收加2.76元，
  页面刷新同步。五站/三十桩预测完整，25桩训练与5桩基线；各时距站桩负荷求和一致。

浏览器自动验收使用Playwright，可先运行
`uv run --with playwright python -m playwright install chromium` 安装本地浏览器。
