# 初始化指南

## 工程架构

本项目采用 CMake + 多子模块的工程组织架构。建议使用 VSCode + Qt Creator 作为主力编码环境，其中 VSCode 提供代码补全、符号跳转和AI功能，Qt Creator 用于可视化设计及 GDB 断点调试。顶层 `CMakeLists.txt` 配置了自动软链接，无论在 Qt Creator 中如何构建，clangd 都会保持实时索引，无需手动配置。

## 环境准备

安装工具链：

```bash
bash scripts/setup_env.sh
```

然后安装 VSCode 扩展：`clangd`（不要装微软官方 `C/C++` 插件）。

只需通过 Qt Creator 完成一次项目载入与初次编译：

1. 克隆仓库：
```bash
git clone https://github.com/windlandneko/bitse-bydxxq
```

2. Qt Creator：打开 Qt，点击 `Open Project`，选中仓库根目录下的 `CMakeLists.txt`，然后直接点击右下角的 「Configure Project」。

3. 初次构建：确保左下角构建模式为 Debug，点击左下角的锤子图标（Build） 或按下快捷键 `Ctrl + B`。此步骤会自动生成 Qt 的 `ui_*.h`、`moc_*.cpp` 并在根目录自动链接 `compile_commands.json`。

4. VS Code：直接用 VS Code 打开项目根目录文件夹。此时打开任意 `.cpp` 文件，C++20 语法高亮与全套 Qt 补全应该生效。

5. Web 开发：运行 `npm run dev` 启动 Vite，Qt Debug 构建直接加载 `http://localhost:5173` 热更新；对于 Release 构建运行 `npm run build`。

## 最佳实践

### Qt UI 设计

1. 在 Qt Creator 的项目树中，双击对应的 `.ui` 文件，进入可视化 Designer 界面拖拽控件、调整布局并保存。
2. 在 Qt Creator 中点击左下角的锤子图标（或者按 `Ctrl + B`）构建。
3. 切换回 VS Code 打开对应的 `.cpp` 文件，此时输入 `ui->` 即可直接补全刚才添加的新控件。

### Debug

遇到复杂的逻辑 Bug 时，切回 Qt Creator，在代码行号左侧单击可以打断点。点击左下角的绿色虫子图标（Start Debugging，或者按 `F5`），即可在图形化变量窗口中查看 `QObject` 树结构与指针状态。

### Release

点击 Qt Creator 左下角的电脑图标，将构建模式切为 Release 并点击构建（注意选择正确的项目！）。CMake 会自动将根目录的索引切至 Release 产物，构建生成的二进制文件位于同级 Release 目录下。
