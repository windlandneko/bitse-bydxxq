# 数据库函数调用说明

此文替代旧版“GUI直接操作SQLite”的函数约定。外部模块使用
[接口契约](接口契约.md)，不要自行读取 `platform.db` 或拼装数据库查询。

## 服务内部

`apps/server/Database.h` 封装工作线程专属的 QSqlDatabase，生命周期在 `Service` 内。

| 方法 | 返回/用途 |
| --- | --- |
| open(directory, seed) | 打开并校验目录内platform.db，原子初始化结构与演示数据 |
| execute(sql, values) | 预处理执行，无返回结果 |
| insert(sql, values) | 预处理执行，返回lastInsertId |
| row(sql, values) | 首行QJsonObject，没有结果为空对象 |
| rows(sql, values) | 所有行QJsonArray |
| Transaction tx(db) / tx.commit() | BEGIN IMMEDIATE，显式提交，析构时未提交则回滚 |

```cpp
Transaction tx(db_);
auto previous = db_.row("SELECT balance_cents FROM users WHERE id=?", {userId});
// 执行业务检查，所有数值通过绑定参数传入。
db_.execute("UPDATE users SET balance_cents=balance_cents+? WHERE id=?", {amount, userId});
// 同一事务内还需写入对应钱包流水和审计日志。
tx.commit();
```

`Database` 不吞掉错误；抛出 BusinessError，由服务入口生成统一错误响应。数据库内部
错误写日志，客户端收到可理解的提示，不收到底层SQL或文件路径。不要在已有Transaction
里新建嵌套事务：充值/预约由请求入口包裹，其他订单和管理动作在各自业务函数内包裹。

## Qt客户端

```cpp
api.call("user.login", {{"phone", "13800000001"}}, [](QJsonValue result) {
  // 登录成功后ApiClient保存Token，后续调用自动携带。
});
api.call("stations.list", {{"latitude", 31.23}, {"longitude", 121.47}},
         [](QJsonValue result) { /* 更新界面模型 */ },
         [](QString message) { /* 展示中文错误 */ });
```

CMake链接 `charging-client`，仅使用 `Qt6::Network`，不链接 `Qt6::Sql`。
金额在协议中使用分。例如充值0.01元发送 `amountCents:1`，请求带独立UUID
`idempotencyKey`。UI禁用正在执行的提交按钮，服务幂等仍是最终保障。

## Web与Python

大屏只读 `GET /api/dashboard`；金额字段为展示用元，不能直接拿来写业务钱包。
`scripts/export_dashboard.py` 可通过API导出只读JSON快照，不连接SQLite。
Python仅接收会话及站桩的JSON输入，输出完整预测，由C++校验后保存到forecasts。
API返回与模型协议字段详见接口契约，预测方法详见 `ml/README.md`。
